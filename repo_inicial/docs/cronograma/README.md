# Cronograma

- `gantt.png`: diagrama de Gantt actual.
- `tareas.csv`: tareas con fases, fechas, horas y predecesoras.
- `gantt.py`: script de Python (matplotlib) que genera el diagrama a partir del CSV.

Para actualizarlo: modifica `tareas.csv`, ejecuta `python gantt.py` y sustituye `gantt.png`. Las flechas de dependencias principales están definidas en la lista `deps` del script.
